# РГВИА: справка для очной работы в читальном зале

**Кому:** любому участнику проекта, кто поедет в РГВИА лично или будет готовить тематический
запрос. Онлайн из этого архива взять нечего — всё ниже предполагает работу на месте.

Дата составления: 2026-10-04. Источники: путеводитель РГВИА в базе Росархива
(`guides.rusarchives.ru`, путеводитель 15), сайт архива `ргвиа.рф`, собственная разведка
базы электронных описей `бд.ргвиа.рф`.

**Прямое попадание, зафиксированное в путеводителе:** в ф. 416 «Генеральные карты России» —

## 4. Порядок работы в зале (по шагам)

1. **Оформление пропуска** и личного дела пользователя — заранее, в первый приезд; приходить
   к открытию (допуск с 09:45), лучше в среду.
2. **Описи — сначала электронные.** Фонды 414, 416, 417, 418, 421, 422, 423 доступны в зале
   в электронном виде: открыть опись, **найти географический указатель**, выбрать разделы
   «Смоленская губерния», «Калужская губерния», «Пермская губерния», «Ярославская губерния».
   Указатель — главный инструмент: он превращает 851 ед. хр. фонда 416 в десятки адресных строк.
3. **Бумажные описи заказываются бланком** — на каждый фонд свой бланк, с номером фонда,
   номером описи и названием фонда. Это нужно для 846 и 386 (электронных описей у них нет).
4. **Выписка.** По каждой найденной единице хранения записать поля из раздела 5 ниже.
   Выписывать сразу в наш формат — иначе материал придётся сверять повторно.
5. **Заказ дел.** Подать «Заказ на выдачу дел» до 16:00 (в среду до 19:00); при наличии в
   фонде связок/столов/отделений — указать их обязательно. Выдача — на следующий рабочий день.
6. **Копирование.** Своим аппаратом — по заявлению о копировании собственными техническими
   средствами; заказ копий у архива — «Заявка на изготовление копий» (платно, по прейскуранту).
   Для карт большого формата уточнить, допускается ли съёмка и на каком оборудовании.

## 5. Что выписывать: поля для нашего каталога

Выписывать так, чтобы запись можно было внести в каталог без дополнительных уточнений:

| Поле | Пример / пояснение |
|---|---|
| Архив, фонд, опись, единица хранения | РГВИА, ф. 416, оп. 1, д. 000 (+ связка/стол/отделение, если есть) |
| Заголовок дела | дословно по описи |
| Датировка: нижняя и верхняя | как в описи; приблизительная дата — помечать отдельно |
| Количество листов | из описи |
| **Масштаб** | дословно с карты («5 вёрст в дюйме», «1 : 42 000»); пересчёт: вёрсты × 42 000, сажени × 84 |
| Территория | губерния + уезд; если на листе несколько уездов — перечислить |
| Тип источника | отдельная карта / атлас-серия / план населённого пункта |
| Условные обозначения, экспликация | состав угодий, что показано — для карт землепользования это главное |
| Физическое состояние | ветхость, утраты — влияет на выдачу и на съёмку |
| Есть ли копия фонда пользования | если да — работать с ней, подлинник могут не выдать |

Ориентир формата — колонки нашего набора по ГАСО ф. 259
(`output/gaso_f259_opis1_vision_20261004/records.csv`): `archive, fund, opis, n, delo, uezd,
svyazka, title, year_from, year_to, year_approx, sheets, note`.

## 6. Альтернатива поездке: тематический запрос

Если поездка не складывается, архив исполняет **тематические запросы — платно**, форма на
`ргвиа.рф/tematicheskie-zaprosy.shtml` (или `zapros@rgvia.com`). Срок исполнения **продлён
до 3 месяцев** (официальное уведомление архива со ссылкой на п. 46.7 Правил, приказ Росархива
от 02.03.2020 № 24). Формы результата на выбор: архивная справка, электронная копия,
**тематический перечень**.

Для нас осмысленная формулировка — **именно «тематический перечень»**, а не справка: нам нужны
не сведения, а список единиц хранения. В запросе указывать: фонды **416, 414, 418** (и при
желании 846), территории — четыре губернии, хронологические рамки, и прямо ссылаться на
**географические указатели к описям** этих фондов. Запрос, в котором назван фонд и указатель,
исполняется совсем иначе, чем «есть ли у вас карты Смоленской губернии».

## 7. Чего НЕ делать (уже проверено, не тратить время)

- **Не искать эти фонды в «Электронных описях» `бд.ргвиа.рф`** — проверен поиск по номерам
  414, 416, 418, 419, 420, 421, 846, 827 и по словам «Генеральные карты»,
  «военно-топографические»: **0 результатов во всех случаях**. В базе только XX век.
- **Не рассчитывать на пагинацию выдачи** этой базы, если всё же понадобится: ссылка
  `/search/pager?...` отдаёт пустой ответ — и из скрипта, и при клике в браузере; видны
  только первые 10 результатов на запрос. Обход — дробить запрос (уезд, год, номер фонда).
- **Не искать в тематических перечнях на сайте архива** — они не касаются картографии
  (благотворительность, Крымская война, история полков, кадетские корпуса, русско-японская война).
- **Систематический каталог архива карточный** (381,9 тыс. карточек) и в электронный вид не
  переведён; именной — тоже карточный. Онлайн оцифрован только слой описей XX века.
