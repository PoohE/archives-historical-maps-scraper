- Запись новых файлов в `D:\Yandex.Disk\...` из shell песочницы Codex может
  завершаться `Access denied`; это ограничение среды, а не ошибка синхронизации.
- Не отключать TLS и не возвращать `verify=False` в Росархиве.
- Для РГБ нельзя использовать старую схему `updatedFields` строкой и нельзя
  фильтровать `cols[]=map` без подтверждения состояния формы.
- ГАРФ — старые `cf/co` из скриншота устарели; сначала открывать `v=2` фонда
  и брать ссылку `v=5` на Оп.1. Сервер ограничивает частоту и может давать
  `ReadTimeout`; используется одна повторная попытка.
