# ⚠️ Облачный воркфлоу «ИГИС — Поиск карт» ОТКЛЮЧЁН (2026-08-24)

## Что случилось
GitHub Actions `search.yml` в репо `PoohE/archives-historical-maps-scraper` падал 4 раза в сутки
минимум с 22.08.2026: `RuntimeError: NOTION_TOKEN не найден`. Причина — в репозитории
**пропали ВСЕ секреты** (`gh secret list` пуст). Токен на локальных дисках не найден.
Воркфлоу отключён вручную: `gh workflow disable search.yml` (статус disabled_manually).

## РЕШИТЬ при следующем обращении к задаче ИГИС
**Нужен ли этот воркфлоу вообще — или удалить?**

Аргументы за удаление:
- перебор комбинаций (49 территорий × 5 слов × 5 готовых источников) мог уже завершиться —
  проверить `--run-dir cloud` прогресс в артефактах Actions / выгрузках
- дальнейшая работа (7 partial-источников: ГАРФ, Калуга Веб-ИРБИС и др.) требует доработки
  скраперов, а не перезапусков старого перебора

Аргументы за реанимацию:
- накопительный режим `--resume` дёшев: доискивает новое без участия ПК
- табло здоровья архивов в Notion обновлялось только им

## Как реанимировать (если решено оставить)
1. Выпустить новый интеграционный токен Notion: notion.so/my-integrations
   (старый утрачен вместе с секретами репо; интеграцию расшарить на базу здоровья архивов)
2. `gh secret set NOTION_TOKEN --repo PoohE/archives-historical-maps-scraper`
3. `gh workflow enable search.yml --repo PoohE/archives-historical-maps-scraper`
4. Прогнать вручную: `gh workflow run search.yml` → проверить зелёный запуск

## Как удалить (если решено закрыть)

  он используется локально)
