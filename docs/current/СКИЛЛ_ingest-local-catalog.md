# Скилл: разбор и заполнение локальных каталогов коллег (ветка-1)

Разбирает структурированные CSV-каталоги коллег (архивные дела/библиотечные карточки, найденные
вручную) и заливает/дозаполняет их в «Каталог» Notion по канону v1.6. Движок —
`scripts/ingest_local_catalog.py`; общая логика территории — `scripts/modules/territory_resolve.py`.

## Когда применять
- Коллега прислал CSV/таблицу с колонками вида Губерния/Уезд/Архив/Фонд/Опись/Дело/Название/Год/
  Листов/Примечание/Ссылка[/Описание]. Файлы кладём в `sourse/`.
- Записи могут быть уже в Notion (ветка-1 заливалась раньше «сырой») → это **retrofit**: движок
  дозаполняет ПУСТЫЕ поля по URL/шифру, защищённые (Статус приёмки/Автор/Дата/геопривязка) не трогает.

## ⚠️ Перед заливкой — проверить планы общего прогона (правило пользователя)
Если архив/библиотека этих строк **в очереди на общий прогон, который создаст ИМЕННО эти записи**
(тот же домен/URL) → **не трогать**, дождаться прогона и сверить, что все попали. Если активного
прогона под эти записи нет → заполнять сейчас.
- Практика 2026-09-27: CSV-строки — на портале `online.archives.ru` (Росархив, #11 — 🔴 заблокирован,
  нужен рос. IP). Общие прогоны РГАДА (`rgada.info`) и РГИА (`fgurgia.ru`) — на РОДНЫХ доменах,
  создают ДРУГИЕ записи (другой URL), эти online.archives.ru-строки не покроют. Значит РГВИА/ГАРФ/
  РГИА/РГАДА-строки из этих CSV **заполняем сейчас** (никакой прогон их не заполнит), а «Описание/
  Что заказывать» коллег вообще уникальны.
- Фильтр по архиву: `--archives РГВИА,ГАРФ`.

## Запуск
```
python scripts/ingest_local_catalog.py [csv...] [--archives РГВИА,ГАРФ] [--date 2026-09-27]   # dry-run
python scripts/ingest_local_catalog.py --apply ...                                            # запись
```
Без csv — берёт `sourse/kaluga.csv` + `sourse/perm.csv`. Всегда сначала dry-run, смотрим создано/
дозаполнено/пропущено, потом `--apply`.

## Разбор «Название» (parse_title) — детали выносятся из названия в поля
Название Алейникова несёт подробности; `parse_title()` их вычищает:
- **Масштаб**: хвост `. Масштаб: X` или inline `в 1 дюйме N верст` / `1:N` → «Оригинальный масштаб»
  (как в оригинале) + «Масштаб (знаменатель)» = `convert_scale` (напр. 20 вёрст/дюйм → 840000);
- **Язык**: `на русском и французском языках` → «Язык» (несколько → первый + прочие в Примечания);
- **Техника**: `Рук.`→Рукописная, `Грав.`/`Гравировал <Ф>`→Гравюра; `Гравировал <Ф>`→«Автор / составитель»;
- чистое имя → «Название источника»; **ПОЛНОЕ название → «Описание»** (мастер-текст) + заметка коллеги.

## Маппинг колонок → поля v1.6
| CSV | поле | примечание |
|-----|------|-----------|
| Название (чистое) | Название источника | подробности вынесены (см. parse_title); пусто → из «Описание» |
| Название (полное) | Описание | ПОЛНОЕ название + заметка коллеги («Описание»/«Примечание») |
| Ссылка | Ссылка на онлайн-архив | дедуп по URL; без ссылки → дедуп по **Фонд+Опись+Дело** |
| Архив | Архив хранения (relation) | РГВИА/РГИА/РГАДА/ГАРФ → справочник «Архивы» |
| Фонд/Опись/Дело | Фонд/Опись/Единица хранения | архивный шифр РАЗЛОЖЕН; композит — формула «Шифр архива». **В «Библиотечный шифр» НЕ писать** (поле 8 — только библиотеки) |
| Год | Год создания нижняя/верхняя | `1829`→оба; `1847-1848`→диапазон; `б/д`→пусто; `18-19 вв`→1701–1900; `80е 18 в`→1780–1789 |
| Губерния+Уезд | Охватываемая территория + Современные регионы | как hints в `territory_resolve` |
| Листов | Листы / страницы | локатор листов дела (канон поле 7); мусор «нд» → пусто |
| Что заказывать | Примечания | служебное коллеги |
| Название (полное) | Тип источника + DC Type | `sweep_candidate_type.classify` (A1–C8) |

## Перезанос по единым правилам (--overwrite)
`--overwrite` перезаписывает re-derived поля у существующих записей (перезанос кривой ранней заливки);
без флага — только пустые. `--author` — «Автор внесения» новых записей (по умолч. «Алейников»).
Дедуп: URL, а для строк без ссылки — по архивному шифру Фонд+Опись+Дело.

## Как добавить новый каталог с ДРУГИМИ колонками
Один словарь `COLMAP` в `ingest_local_catalog.py` — добавить псевдонимы новых заголовков →
канонические ключи (`gub/uezd/arch/fund/opis/delo/title/year/sheets/note/url/descr/order`).
Больше ничего менять не нужно — маппинг на поля общий.

## Гейт готовности
`ruff check` → dry-run (числа осмысленны) → `--apply` → сверить заполняемость в Notion.
Территория/регион теперь заполняются и при обычной заливке через мост (правило встроено в
`notion_upload_candidates.py` + `territory_resolve`); этот движок — для CSV-каталогов, не онлайн-скрапа.
