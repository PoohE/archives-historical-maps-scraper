### ⚠️ КРУПНАЯ ПОПРАВКА: доступ ПрБ (случай 11) — переделать на батче

огульное «ПрБ → Ограниченный доступ» (мой sweep_access_status) НЕВЕРНО для текстовых источников —

статусы ПрБ считать ПРОВИЗОРНЫМИ (Ограниченный, вероятно, занижен).

  `convert_scale` → «Масштаб (знаменатель)» (29). `cartographic_enrichment.convert_scale` уже умеет
  «1:N» и «N вёрст в дюйме» — нужно лишь ИЗВЛЕЧЬ строку масштаба из описания и подать ему;
- **условные знаки** → «Типы отображаемых объектов» (44): «Усл. знаки: границы; дороги; воды;
  насел. пункты; фабрики и заводы» ↔ Приложение Б (адм. границы / пути сообщения / гидрография /
  населённые пункты / промышленные объекты). Парсить список после «Усл. знаки:»;
- **цветность**: «: цв.» → Цветность скана = Цветной; «: ч.-б.»/«черн.» → Чёрно-белый.
Канонно (данные ЯВНО в карточке, не угадывание; не OCR — текст уже есть). Применимо к prlib и другим
RUSMARC-описаниям (РНБ/ГПИБ). → внесено в `ЗАДАНИЕ_адаптеры…` как «текстовый парсинг физ./карт.
характеристик из описания».

## Закономерности «Статус приёмки» (свод по 19 случаям, для фильтра)
**ПРИНЯТО** (keep), если хоть одно:
- прямая карта/атлас/план (в названии или описании) — правило 2/positive (случаи 6,8,15→карта,16,18,19);
- **карта ВНУТРИ** текста: маркеры «с картой/с планом/с картами», «N л. к.», «л. карт», «карта приложена»
  → форсировать keep даже для текстового типа (случаи 2,5,16);
- травелог/описание о НАШЕЙ территории (путешествие/путевые записки) — случай 11;
- субъект = губерния/уезд/наместничество нашего региона (случаи 5,16);
- серийный источник нашего корпуса (Кирилов/Ремезов/Руднев-1913/Материалы/Чердынский) — 7,9,10,18.

**ОТКЛОНЕНО** (drop), если:
- субъект = отдельный НАС. ПУНКТ (город/село/деревня/…), уезд/губ. лишь адрес — 1,4,14;
- ЧУЖОЙ регион: по названию, по тематическим рубрикам описания, по СОКРАЩЕНИЮ губернии
  («Владим.»), причём **чужая губерния бьёт совпадение уездного стема** — 3,15;
- военные кампании/действия (поход/осада/сражение/дипл. переписка) — 12;
- делопроизводство/штат без карты (дело о…/записка/рапорт/штат) — 13,17.
**Правило удаления отклонённых (обновляет прежнее «не удалять»):** причины отклонения
кодифицируются в этот журнал + регресс-тесты; после этого сами записи **архивируются** из Notion
(`scripts/maintenance/archive_rejected.py`, archived=true — обратимо). 8 отклонённых ПрБ
архивированы 2026-09-26.
