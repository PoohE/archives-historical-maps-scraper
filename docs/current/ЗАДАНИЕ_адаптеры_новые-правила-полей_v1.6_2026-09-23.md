# Задание сессии отладки скриперов: новые правила раскладки полей каталога (v1.6)

**Кому:** соседняя сессия, отлаживающая скрипты вытягивания данных с карточек (адаптеры источников).
**От:** сессия разбора полей каталога (РНФ). **Дата:** 2026-09-23. **Модель:** Opus 4.8.

## Зачем
Система полей каталога переработана (разбор Д1–Д20): часть полей слита/упразднена, добавлено
производное поле фильтрации, уточнена семантика держателя/автора/места/языка. **Все адаптеры**
(`prlib_card` и прочие: `neb_notion`, `rgada_notion`, `rgia_notion`, `permkrai_notion`,
`export_gpib_notion`, `rnb_*`, `rsl_*` …) должны раскладывать данные с карточек по этим правилам,
единообразно. Цель проекта: **максимум информации с карточки для ручного поиска + правильная
раскладка по полям.**

## Сквозной принцип
**Есть в карточке — вносим в соответствующее поле; пусто оставляем только когда данных реально нет.**
Не заполнять предположением. Спорное/неоднозначное — кандидат + review-флаг, не произвольный выбор.

## Правила раскладки (Д1–Д20)

| Данные карточки | → Поле | Правило |
|---|---|---|
| держатель оригинала (РГБ/ЦВМБ/…) | **Архив хранения** (relation) | НЕ в «Место хранения»; агрегатор (ПрБ/НЭБ) → держатель из карточки; связь только с существующей записью справочника «Архивы» (новый держатель — вопрос) |
| архивный шифр в держателе («РГИА.Ф.1290.Оп.4.Д.68») | **Фонд / Опись / Единица хранения** | распарсить; Архив=держатель |
| источник эл. копии | **Организация оцифровки** | — |
| **весь текст карточки ИСТОЧНИКА** | **Описание** | одно поле; **поле «Библиографическое описание» упразднено** (слито сюда) |
| год | **Год создания (нижняя/верхняя) + Год сведений** | единичный точный → нижняя; диапазон → +верхняя; библиотека без даты создания → год издания в верхнюю с пометкой «(авто)»; год сведений при наличии. **«Год источника» — формула Notion, маппер её НЕ пишет** |
| издание | **Связанное издание: название/тип/автор/год/URL** (5 полей) | ответственность издания сюда (автор); **поле «Связанное издание: библ. описание» упразднено** (по URL); URL издания — только настоящий, иначе пусто |
| автор **карты**/ведомство-изготовитель | **Автор / составитель** | НЕ ответственность издания (та → «Связанное издание: автор/ответственность»); нет автора карты → пусто (норма) |
| место издания/создания источника | **Место создания** | **прогонять через `place_normalize.normalize()`** — внятный топоним в им. падеже, современная орфография («Санктпетербург»→«Санкт-Петербург»), снять `[]` и предлог; имя эпохи сохранять (Свердловск); мусор/с цифрами → пусто; нет своего → авто из места издания (`recover_from_description`); важно для фильтра |
| локатор листов | **Листы / страницы** | объём издания → в «Описание», не сюда |
| папка/пром. уровень | **Место хранения** | обычно пусто у библиотек |
| все шифры карточки | **Библиотечный шифр** | через `;` с префиксами учреждения/типа; первым — нативный держателя. Единый ID записи — формула «Шифр записи» |
| тип | **Класс и тип (A1–C8)** + **DC Type** | кандидат по правилам + флаг «сомнительный тип»; конфликт → пусто; DC Type авто от A/B/C по объекту. **Референс-реализация правил классификации по названию — `scripts/maintenance/sweep_candidate_type.py` (RULES, канон табл. 7): перенести в адаптер/triggers, чтобы тип шёл у ВСЕХ источников (сейчас правила применены разово к ПрБ). «Код типа [авто]» и «Шифр записи» — производные от «Тип источника», отдельно не писать.** |
| язык | **Язык** | **авто «Русский»**, если в карточке явно не указан другой (проектное правило) |
| территория | **Охватываемая территория / Адм. уровень / Совр. регионы** | только подтверждённая единица справочника (морфо-совпадение); иначе пусто + флаг «регион неясен»; уровень из единицы; регионы авто от территории |
| серия | **Серия / массив + Номер в серии** | по алиасам справочника; детектор A (маркеры «Лист/Том/Вып/№/Ч.») + детектор B (кластер прогона ≥3); новую серию авто НЕ создавать (эксперт). **ИНВАРИАНТ Д18: «Номер в серии» пишется ТОЛЬКО вместе с «Серия / массив» — том/выпуск без связанной серии не выводить (останется в «Описании»).** Серия есть в справочнике → link; серийный сборник (в т.ч. статистич./описательный) не найден → кандидат в новую серию эксперту (справочник «Серийные массивы» единый для карт и стат./опис. серий, различие — поле DC Type). Референс алиасов — `scripts/maintenance/fix_series_number.py::SERIES`. Страж в мосте `notion_upload_candidates.py` уже отбрасывает номер без серии |
| статус доступа | **Статус доступа** (16) | авто по правилу: галерея титульных → Ограниченный; цифр. копия есть (19/63) → Открытый; нет копии/галереи → Только метаданные; эмбарго/читальный зал/регистрация → Эмбарго/Ограниченный. Референс — `scripts/maintenance/sweep_access_status.py` |
| атрибуты скана (год скан., DPI, качество, цветность, формат, размер, лицензия) | **Блок IV** | вносим, **если есть в карточке**/файле; иначе пусто |
| геопривязка/векторизация/OCR/координаты/GCP | **статусные поля** | дефолт «Не выполнена/Нет/Не привязан/пусто» — наша работа; при обновлении не сбрасывать (защищённый список импортёра) |
| физич. состояние, размер листа | **41/42** | если есть в карточке |
| — | **Примечания** | наши аналитические пометки (review-флаги, основания типизации), НЕ текст карточки |
| служебные | Автор внесения=**Агент**, Дата внесения, Статус приёмки=**кандидат**, Причина сомнительности | как в мосте |

**Агрегатор** отдельным полем не фиксируем — он виден по домену «Ссылки на онлайн-архив» (URL карточки).

## ⚠️ ГПИБ (`export_gpib_notion`, elib.shpl.ru) — адаптер до-v1.6, БРАК на интейке
Проверка 5 записей ГПИБ в Notion (2026-09-26): **«Описание» пусто 5/5, ссылка на изображение
не снята 5/5, названия склеены без пробелов** («Картаадминистративного деления Ярославскойгубернии»).
Нужен ретрофит адаптера + **пере-сбор** этих 5 записей:
- **текст карточки → «Описание»** (сейчас пусто — главный дефект);
- **починить извлечение названия** (пробелы: HTML-узлы склеиваются без разделителя → добавлять пробел
  при конкатенации текстовых узлов);
- **снять ссылку на изображение/файл** из тайлового просмотрщика elib.shpl.ru (`mode/grid`, `zoom/N`):
  найти download/IIIF-эндпоинт (обычно `.../images/...` или IIIF `info.json` → полный `/full/full/0/default.jpg`).
  Прямой URL скана → поле 19 «Прямая ссылка на файл изображения»; стабильный download/файловый URL →
  поле 63 «Путь / URL к файлу». Оба сейчас пусты (None) → вычисляемый флаг «Цифровая копия (есть/нет)»
  ложно «нет»; заполнение 19 или 63 чинит и флаг. Без URL скана OCR-слой не запустится;
- **снять «Связанное издание» (поля 23–27)**: у ГПИБ тоже пусто — а поле 23 «Связанное издание:
  название» по канону **обязательно для библиотек/порталов** (карта, как правило, из издания —
  атласа/книги/журнала). Снять название/тип/автор-ответственность/год/URL издания, если карта
  входит в издание. Standalone-карта без издания → пусто (это норма, не брак);
- прогнать через общие правила v1.6 (Д1–Д20), как ПрБ.
**Гейт качества (чтобы брак не проходил молча):** картографический источник (тип A*/DC StillImage)
с ПУСТЫМ «Описанием» ИЛИ без ссылки на изображение — не «готово», а флаг на пере-сбор.
Побочно: эти 5 сейчас со статусом «принято» (backfill проставил при пустом статусе) — при пере-сборе
вернуть в «кандидат», это брак, а не принятый источник.

## Текстовый парсинг физ./картографических характеристик ИЗ описания (не OCR!)
Если структурные данные есть в ТЕКСТЕ карточки (RUSMARC-описание: prlib/РНБ/ГПИБ) — извлекать их
в поля СРАЗУ, не дожидаясь OCR с картинки (данные уже есть, канонно — явное указание в карточке).
Пример (карты Д. Руднева 1913, prlib): в «Описании» есть всё, но поля пусты. Парсить:
- **масштаб**: «[1:N]» и «N вёрст в (англ.) дюйме» → «Оригинальный масштаб» (30) +
  `cartographic_enrichment.convert_scale` → «Масштаб (знаменатель)» (29);
- **условные знаки**: список после «Усл. знаки:» → «Типы отображаемых объектов» (44) по Приложению Б
  (границы→адм. границы; дороги→пути сообщения; воды→гидрография; насел. пункты→населённые пункты;
  фабрики/заводы→промышленные объекты);
- **цветность**: «: цв.» → Цветной; «: ч.-б.»/«черн.» → Чёрно-белый (поле 60);
- **техника** (поле 40): «рукописн» → Рукописная; «литогр» → Литография; «хромолитогр» → Хромолитография;
  «гравюр/грав.» → Гравюра; «печатн» → Печатная (акварель/тушь/перо → уточняют рукописную);
- **несколько масштабов** (конволют/атлас): все дословно в «Оригинальный масштаб» (30);
  знаменатель (29) при неоднозначности → пусто + review (канон: несколько масштабов → проверка);
- **связанное издание из описания** (поля 23–27): фразы «приложен(ы)/состоит из карт к изданию:
  <Название>. <Место>, <Год>», «из издания: …», «карты к изданию: …» → Связ.изд.: название (23) /
  год (26) / место можно в примечание; тип (24) по метаданным издания;
- год в квадратных скобках «[1913]» — уже снимается, проверить что доходит до поля года.
Приоритет: явные данные из ТЕКСТА карточки > кандидаты OCR с изображения.
