## ГРАБЛИ (не повторять)
- **Фикс в SWEEP ≠ фикс в адаптере.** Ретрофит существующих записей sweep-ом НЕ мешает новому прогону
  повторить ошибку — правило переносить в адаптер (домен Codex) через бриф. Иначе каждый прогон = новый ретрофит.
- **Единица РГАДА = опись, текст описи — в URL `?opisanie=`, не в title/desc.** Название/Описание строить
  из него. «Алфавит № N» — отдельная короткая аннотация (номер алфавитного указателя дач), НЕ в URL-тексте;
  Описание = текст описи + аннотация.
- **РГАДА-описи — реестры серийных карт, не сами карты** → привязка к Серии «Генеральное межевание»
  обязательна (когда «межевани»). Сканы СТРАНИЦ описи в поля файла (19/63) НЕ лить — per-дело позже.
- **Разные домены = разные записи.** Общие прогоны РГАДА/РГИА на родных доменах (rgada.info/fgurgia.ru)
  НЕ покрывают online.archives.ru-строки коллег (дедуп по URL). РГВИА официально идёт ЧЕРЕЗ online.archives.ru
  (Росархив #11, 🔴 заблокирован) — свои прогоны его не заменят → заполнять из CSV коллег.
- **Сеть флапала (`getaddrinfo failed`).** Все движки идемпотентны (дедуп/заполнение пустого) — просто
  перезапускать. **PowerShell-пайп (`| Select-Object`) прячет exit code python** → падение выглядит как
  успех; для важного вывод писать в файл (`> out.txt 2>&1`), потом читать.
- **Notion: «Место хранения» (папка) ≠ «Архив хранения» (учреждение, relation) ≠ «Листы / страницы»
  (локатор листов дела). «Архив [авто]» — rollup аббревиатуры через «Архив хранения».**
