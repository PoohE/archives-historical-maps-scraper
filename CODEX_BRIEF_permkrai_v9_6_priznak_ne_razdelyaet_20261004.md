`needs_human=true` — **51 из 51**. В v9.4 было наоборот: бесспорными объявлялись ровно те
14 записей, которые брать нельзя. Оба раза признак не выполняет свою работу — **разделять
бесспорное и спорное**. Сейчас он просто переложил весь набор на человека.

Что это ломает: по такому полю нельзя ни отфильтровать данные для импорта, ни распределить
ручную проверку, ни измерить качество гейта. Поле, одинаковое у всех записей, информации не несёт.

## Разделение возможно — оно уже есть в ваших же данных

Разбор поля `evidence` по тройке (subject / territory / level) даёт четыре разных класса,
которые сейчас слиты в один:

| subject | territory | записей | чем это является на самом деле |
|---|---|---|---|
| `subject_unconfirmed` | `other_region_in_title` | **14** | предмет не подтверждён И территория чужая → это `scope_drop: out_of_region`, а не вопрос к человеку |
| `cartographic_term_in_item_title` | `other_region_in_title` | **4** | предмет картографический, но территория чужая → `scope_drop: out_of_region` |
| `subject_unconfirmed` | `target_region_in_title` | **26** | наша территория, предмет под вопросом → **законный `needs_human`** |
| `cartographic_term_in_item_title` | `territory_unknown` | **5** | карта есть, территории нет → **законный `needs_human`** |
| `atlas_link_candidate` / `fieldwork_plan_candidate` | `target_region_in_title` | **2** | кандидаты по §1.1 → **законный `needs_human`** |

То есть при той же логике отбора набор делится на **~18 отсечений** и **~33 записи на проверку**
вместо «51 на проверку». Классы уже вычислены сборщиком — он просто не использует их для вердикта.

## Требование к v9.6

1. **Вердикт выводится из тройки evidence, а не ставится одинаковым для всех.**
   - территория чужая (`other_region_in_title`) и предмет не подтверждён → `scope_drop`
     с `scope_drop_reason=out_of_region`;
   - наша территория + подтверждённый картографический предмет + уровень не городской →
     `keep`, `needs_human=false`;
   - всё промежуточное → `needs_human=true` с причиной в отдельном поле
     (`needs_human_reason`: `subject_unconfirmed` / `territory_unknown` / `atlas_link` / `fieldwork_plan`).
2. **`needs_human_reason` обязателен**, когда `needs_human=true`: без причины список неразбираем.
3. **В отчёте — распределение вердиктов и причин с числами**, а не только итог.
4. Если по правилам отбора бесспорных записей в наборе действительно нет — это надо **заявить
   отдельной строкой отчёта** с обоснованием, а не выставлять флаг по умолчанию всем.

## Общее правило (вносится в регламент приёмки, п. 11)

**Признак, одинаковый у 100 % записей, считается не выставленным.** Поле-вердикт обязано делить
набор; если оно не делит, сдающая сторона либо показывает, что набор однороден по существу,
либо признак переделывается. Это третье замечание по одному и тому же пункту — по правилу
второго раза оно выносится из переписки в регламент.
