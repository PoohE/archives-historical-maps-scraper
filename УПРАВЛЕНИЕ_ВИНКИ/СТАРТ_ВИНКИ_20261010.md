## 1. Первое, что сделать (одна минута)

**Первым сообщением в сессии напиши ровно:** `ВИНКИ-ПРОГОНЫ`

Это станет заголовком сессии, по нему Тинки найдёт тебя в списке и сможет писать напрямую.
Если прямая связь не поднимется — общаемся файлами: ты пишешь в `УПРАВЛЕНИЕ_ВИНКИ\ОТЧЁТЫ\`,
Тинки читает оттуда.

Затем сообщи Тинки три факта:
- исходящий IP и страну (`curl -s https://ipinfo.io/json`);
- свободную оперативную память;
- что видишь папку `D:\Yandex.Disk\History&Geography\БД\Поиск онлайн архив`.

## 2. Твоя роль — только прогоны

Ты запускаешь долгие сборы и отдаёшь результат. **За разбор, приёмку, каталог и решения
отвечает Тинки.**

НЕ делать: git-коммиты, запись в Notion, правку движков и параметров прогона, изменение
правил отбора, брифы Codex, работу с чужими папками `output/`.

Падение прогона — **находка для отчёта, а не повод чинить код.** Сообщи: что запускал,
на чём встало, последние строки лога, код выхода. Тинки починит и вернёт задание.

## 3. Что запускать прямо сейчас — задание З-007 (ГАСО)

Полный текст: `УПРАВЛЕНИЕ_ВИНКИ\ЗАДАНИЯ\З-007_gaso_karta_opisei.md`. Коротко:

```powershell
cd "D:\Yandex.Disk\History&Geography\БД\Поиск онлайн архив"
python -B scripts_gaso\gaso_scan_collector.py --map 1-1200
```

- Запускать **detached-процессом** (`scripts_rosarchive\run_detached.ps1`), не фоновой
  задачей сессии: сессию могут закрыть, процесс должен пережить.
- Выход — `C:\arch\output\gaso_scans_<дата>\` (локально, НЕ на Яндекс.Диск).
- Возобновление встроено: при обрыве просто повтори ту же команду.
- Темп 1,6 с между запросами **не менять**. Три ответа 403/429 подряд → штатная остановка,
  в отчёт.
- Ожидание ~2 часа. Промежуточный срез через час.
- **Шаг 2 (скачивание сканов) не начинать** — только после того, как Тинки сверит карту.

## 4. Как отчитываться

Файл в `УПРАВЛЕНИЕ_ВИНКИ\ОТЧЁТЫ\З-007_<дата>.md` плюс сообщение Тинки, если связь есть:

- сколько id пройдено из 1200;
- сколько описей со сканом найдено;
- какие из наших 24 фондов встретились (номера), какие пока нет;
- строки с неразобранной подписью файла — **выписать дословно**, не угадывать фонд;
- что остановило прогон, если остановился.

## 6. Три правила, на которых уже обжигались

1. **robots читать целиком.** По ПрБ вывод «запрета нет» сделали по первым 22 строкам, а
   `Disallow: /search` стоял на 69-й — бриф пришлось отзывать.
2. **Не выдавать парсерную ошибку за блокировку.** HTTP 200 с телом в 50 КБ — это не бан,
   даже если в тексте страницы есть слово «доступ ограничен». Классификация остановки — по
   коду ответа.
3. **Живость прогона проверять по процессу-циклу**, а не по короткоживущему дочернему
   скрипту, и не по тому, что фоновая задача сессии «завершилась».
