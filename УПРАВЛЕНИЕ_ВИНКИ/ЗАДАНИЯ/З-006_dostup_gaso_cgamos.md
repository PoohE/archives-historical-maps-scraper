# З-006. Переразведка доступа: ГАСО и ЦГА Москвы

Статус: **НОВОЕ** · Условие: после приёмки З-001 · Ожидание: 20 минут
**Только чтение.** Сбор не запускать ни при каком результате.

## Зачем

Два источника стоят не потому, что в них нет материала, а потому что **упёрлись в транспорт**:

| Источник | Как остановился |
|---|---|
| ГАСО (Свердловская обл.) | основной сайт и ф. 259 зафиксированы, портал описей встал на транспортной ошибке |
| ЦГА Москвы | остановлен на транспортной ошибке / robots 403, повтор не назначался |

В чеклисте по ГАСО записано «не повторять **без изменившихся условий доступа**». Условия
изменились: другая машина, другая сеть, возможно российский IP (ответ З-001). Ровно так же
стоял ГАПК — геоблокировка нероссийских IP, — и после смены транспорта дал 19 441 дело.

Поэтому задание дешёвое, а выигрыш возможен большой.

## Шаги

1. robots каждого портала — **полный текст**, выписать все `Disallow`:
   ```powershell
   python -c "import requests
   for u in ['https://gaso-ural.ru/robots.txt','https://cgamos.ru/robots.txt']:
       try:
           r=requests.get(u, timeout=25); print('=====', u, r.status_code); print(r.text)
       except Exception as e: print('=====', u, 'ОШИБКА', type(e).__name__, e)"
   ```
   ⚠️ Читать целиком, не первые строки: по ПрБ вывод «запрета на /search нет» был сделан по
   22 строкам, а `Disallow: /search` стоял на 69-й — бриф пришлось отзывать.

2. Главные страницы — коды ответа и размер, по одному запросу:
   ```powershell
   python -c "import requests
   for u in ['https://gaso-ural.ru/','https://cgamos.ru/']:
       try:
           r=requests.get(u, timeout=25); print(u, r.status_code, len(r.content))
       except Exception as e: print(u, 'ОШИБКА', type(e).__name__, e)"
   ```

3. Если адрес не отвечает вовсе — проверить, не сменился ли домен (один поиск, без обхода),
   и записать найденный адрес в отчёт. Не идти по нему дальше.

## Что в отчёт

- по каждому порталу: код ответа, размер, **полный список `Disallow`**;
- сравнение с прежним состоянием: та же ошибка или другая (прежде — транспортная ошибка и 403);
- вывод одной строкой на источник: изменились условия доступа или нет.

## Чего не делать

- Не запускать `scripts_gaso`, не обходить описи, не собирать дела.
- Не делать серий запросов — это разведка, единичные обращения.
- Не искать объезд запрета robots. Запрещено — доложить. По ПрБ попытка «пройти хоть как-то»
  обернулась тремя сутками прогона по учебной коллекции вместо фонда.
