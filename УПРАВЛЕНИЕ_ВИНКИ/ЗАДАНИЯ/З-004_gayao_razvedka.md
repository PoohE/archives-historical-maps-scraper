# З-004. ГАЯО (af.yar-archives.ru) — только разведка доступа

Статус: **НОВОЕ** · Условие: после приёмки З-001 · Ожидание: 20 минут
**Это разведка, не сбор.** Сбор назначу отдельным заданием после приёмки.

## Зачем

Ярославская губерния — следующая по очереди источников (решение пользователя).
Корпус июльского прогона ГАЯО **не сохранился**: по чеклисту 17.07 было «248 уникальных дел,
ф. 560 оп. 1Т», а инвентаризация 156 папок `output/` 06.10 не нашла ни одного файла с данными
`gayao`. Результат существует лишь числом в чеклисте — собирать заново.

Сентябрьский зонд получал на `robots.txt` **HTTP 403** (вероятно, геоблокировка нероссийских IP).
Отсюда и вопрос: что портал отдаёт с институтской машины.

## Шаги (только чтение, без обхода)

1. robots — полный текст, не первые строки:
   ```powershell
   python -c "import requests; r=requests.get('https://af.yar-archives.ru/robots.txt', timeout=25); print(r.status_code); print(r.text)"
   ```
   ⚠️ **Прочитать robots целиком и выписать ВСЕ `Disallow`.** Прецедент: по ПрБ был сделан
   вывод «запрета на /search нет» по 22 строкам, а `Disallow: /search` стоял на строке 69 —
   бриф пришлось отзывать.

2. Главная и поиск — только коды ответа и размер, без разбора:
   ```powershell
   python -c "import requests
   for u in ['https://af.yar-archives.ru/','https://af.yar-archives.ru/archive/search']:
       try:
           r=requests.get(u, timeout=25); print(u, r.status_code, len(r.content))
       except Exception as e: print(u, 'ОШИБКА', type(e).__name__, e)"
   ```

3. Если 403 — проверить, меняется ли ответ с обычным User-Agent браузера (один запрос,
   не серия). Если и так 403 — на этом остановиться.

## Что в отчёт

- **полный список `Disallow`** из robots (или факт, что robots недоступен — с кодом);
- коды ответа главной и поиска, размеры;
- есть ли на странице поиска признаки AJAX-выдачи (ищется ли что-то без перезагрузки) —
  по разметке, без выполнения запросов;
- вывод: открыт ли портал с этой машины и что из robots ограничивает обход.

## Чего не делать

- Не обходить фонды, не запускать `searcher_gayao.py`, не собирать дела.
- Не делать серий запросов — разведка это единичные обращения.
- Не трогать `/search`, если robots его запрещает: по ПрБ на этом же месте прогон три дня
  шёл по учебной коллекции вместо фонда. Запрещено — доложить, а не искать объезд.
