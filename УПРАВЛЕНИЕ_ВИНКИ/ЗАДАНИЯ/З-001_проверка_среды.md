# З-001. Проверка среды и исходящего IP

Статус: **НОВОЕ** · Приоритет: **первое, до всех прогонов** · Ожидание: 10 минут

## Зачем

От ответа зависит способ работы всех остальных заданий. Если институтский IP российский —
ГАПК, УИАД и ГАЯО открываются обычным `requests`, и весь обход через отладочный Chrome
(CDP) не нужен. Это главный выигрыш второй машины, помимо памяти.

## Шаги

1. Разложить копию по инструкции `../../ПЕРЕНОС_ПРОГОНОВ_НА_ВТОРУЮ_МАШИНУ_2026-10-06.md`,
   раздел 1 — в `C:\arch\` (ASCII-путь без пробелов).

2. Зависимости:
   ```powershell
   python -m pip install requests beautifulsoup4 lxml websocket-client
   python -V
   ```

3. Исходящий IP:
   ```powershell
   python -c "import requests; print(requests.get('https://ipinfo.io/json', timeout=20).text)"
   ```

4. Доступность порталов (каждый — отдельной строкой в отчёте, с кодом ответа):
   ```powershell
   python -c "import requests
   for u in ['https://fgurgia.ru/robots.txt','https://online.archives.ru/','https://archives.permkrai.ru/robots.txt','https://af.yar-archives.ru/robots.txt','https://www.prlib.ru/robots.txt']:
       try: print(u, requests.get(u, timeout=25).status_code)
       except Exception as e: print(u, 'ОШИБКА', type(e).__name__, e)"
   ```
   ⚠️ `online.archives.ru` может упасть на сертификате (`ERR_CERT_AUTHORITY_INVALID` /
   `SSLError`) — это ожидаемо и **не повод для `verify=False`**. Просто запиши как есть.

5. Свободная память: `(Get-CimInstance Win32_OperatingSystem).FreePhysicalMemory/1MB` (ГБ).

## Что в отчёт

- страна и провайдер исходящего IP;
- таблица: портал → код ответа или имя ошибки;
- версия Python, свободная память;
- **вывод одной строкой: нужен ли отладочный Chrome** (нужен, если страна не RU).

## Чего не делать

Прогоны не запускать до приёмки этого задания — порядок запуска зависит от результата.
