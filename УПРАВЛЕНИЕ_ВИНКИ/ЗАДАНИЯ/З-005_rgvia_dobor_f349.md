# З-005. РГВИА, добор фонда 349 — картография вне списка путеводителя

Статус: **НОВОЕ** · Условие: после приёмки З-001 и завершения З-003 · Ожидание: ~1 час

## Зачем

Набор УИАД собран обходом 17 картографических фондов по списку путеводителя. Измерение
межархивным поиском (`output/rgvia_gap_20261005/REPORT.json`) показало: из 57 результатов
**8 пришли из фондов вне списка** — в том числе ф. 349 «Главное военно-техническое управление
(планы и чертежи)», прямо картографический по названию, а также личные фонды генералов.

То есть часть картографии РГВИА лежит в непрофильных фондах. Ф. 349 — самый очевидный пропуск.
Добор согласован пользователем 06.10.

## Запуск

```powershell
cd C:\arch
python -B scripts_rosarchive/collect_uiad_rgvia_maps.py --funds 349
```

Тот же сборщик, что в З-003, тот же механизм состояния: уже собранные описи пропускаются.

**Если фонд не резолвится по номеру** (сборщик ищет фонд через `fund_ids.json` /
путеводитель, а в отчёте о пробеле фигурируют внутренние id вида `10000040939003`) —
**остановиться и доложить**, какой именно ответ дал сборщик. Не подбирать id вручную,
не править код: сопоставление номер → внутренний id сделает Тинки.
