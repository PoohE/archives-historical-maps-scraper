# Задание сессии-грузчику на Винки (разовое, до запуска прогонов)

Это задание для **первой** сессии Claude на ноутбуке ИГ РАН — той, что запущена из обычной
рабочей папки (`D:\IG Dropbox\Andy PoohV\Project\Claude`). Она только переносит файлы.
Прогоны будет вести **другая** сессия, запущенная из `C:\arch` после перезапуска.

Почему две сессии: роль из `CLAUDE.md` подхватывается **при старте** сессии. Пока сессия
запущена из Dropbox, она не видит `C:\arch\CLAUDE.md` и не знает ограничений исполнителя.

## Что сделать

### 1. Проверить, что источник доступен

```powershell
Test-Path "D:\Yandex.Disk\History&Geography\БД\Поиск онлайн архив\УПРАВЛЕНИЕ_ВИНКИ\РОЛЬ_ВИНКИ_CLAUDE.md"
```

`False` → Яндекс.Диск на этой машине не установлен или папка ещё не синхронизирована.
Остановиться и сказать пользователю — без синхронизации дальше идти нельзя.

### 1а. Убедиться, что файлы реально скачаны, а не заглушки

Яндекс.Диск держит часть файлов как **online-only заглушки** (атрибут `0x400000`): на диске
лежит только placeholder, содержимого нет. Копирование такой папки тянет её из облака —
медленно, а при остановленном клиенте не сработает вовсе.

```powershell
$d = "D:\Yandex.Disk\History&Geography\БД\Поиск онлайн архив\output\rgia_fund380_20261003_v3_1"
Get-ChildItem $d -Recurse -File |
  Group-Object { if ([int]$_.Attributes -band 0x400000) {"заглушка"} else {"локально"} } |
  Select-Object Name, Count
[math]::Round((Get-ChildItem $d -Recurse -File | Measure-Object Length -Sum).Sum / 1MB) 
```

Есть заглушки → закрепить офлайн и дождаться докачки (клиент Я.Диска должен быть запущен):

```powershell
attrib +P -U /S /D "$d\*"
```

То же проверить для `output\uiad_rgvia_maps_20261004` (ожидается ~165 МБ) и папок `scripts_*`.
**Пока размеры не совпали с заявленными — не копировать:** получится пустышка, и прогон
фонда 380 начнётся заново вместо продолжения с 25-й описи.

### 2. Создать локальную рабочую папку

```powershell
New-Item -ItemType Directory -Force C:\arch\output | Out-Null
```

Путь обязательно `C:\arch` — ASCII, без пробелов и кириллицы. Половина известных нам
граблей Windows (Playwright, bash-вызовы, кодировки) снимается этим.

### 3. Положить роль

```powershell
Copy-Item "D:\Yandex.Disk\History&Geography\БД\Поиск онлайн архив\УПРАВЛЕНИЕ_ВИНКИ\РОЛЬ_ВИНКИ_CLAUDE.md" C:\arch\CLAUDE.md
```

Именно `C:\arch\CLAUDE.md` — это и есть механизм, которым следующая сессия узнает свою роль.

### 4. Скопировать рабочее

Состав и обоснование — в `ДОСТУП_ВИНКИ_какие_папки.md` (раздел 3). Кратко:

```
из "…\Поиск онлайн архив\"                     в C:\arch\
    scripts_rosarchive\                        scripts_rosarchive\
    scripts_gapk\                              scripts_gapk\
    scripts_review\                            scripts_review\
    scripts\modules\                           scripts\modules\
    output\rgia_fund380_handoff_20261003_v3_1\ output\…\
    output\rgia_fund380_20261003_v3_1\         output\…\   (173 МБ, можно урезать — см. ниже)
    output\uiad_rgvia_maps_20261004\           output\…\   (165 МБ)
    output\rosarchive_rgvia_20261004\fund_ids.json
```

**Урезание ф. 380 (по желанию, экономит ~145 МБ):** вместо всей папки скопировать только
`fund380_opis_state\`, `records.csv`, `records_full.jsonl`, `run_scope.json`,
`fund_inventory.json`, `LATEST_REPORT.json`. Файл `scope_drops.jsonl` (журнал отсева) для
продолжения прогона не нужен.

**Не копировать:** `output\gapk_maps_20261005\` (ГАПК завершён),
`output\prlib_catalog_full_handoff_20261006_v8\` (ПрБ ждёт фикса Codex), остальные ~150 папок
`output\`, `staging\`, `input_*\`, `скрины архивов\`.

## Чего грузчику НЕ делать

| Запрещено | Почему |
|---|---|
| **git commit / push** | В git проекта пишет только Тинки (старый ПК) |
| Запускать любые прогоны | Это работа следующей сессии, по заданиям из `ЗАДАНИЯ\` |
| Править файлы в папке Я.Диска | Зона Тинки; у Винки на запись только `УПРАВЛЕНИЕ_ВИНКИ\ОТЧЁТЫ\` |
| Править скопированный код | Переносчик не редактор |
| Решать, что ещё «пригодится» | Состав определён в `ДОСТУП_ВИНКИ_какие_папки.md` |

которых исполнителю прогонов иметь не надо.
