# Бриф Codex, дополнение к v8: законный маршрут ПрБ — региональные коллекции, не `/search`

Дата: 2026-10-06. Заменяет раздел «задача» в `CODEX_BRIEF_prlib_wrong_collection_20261005.md`.
Приёмку ведёт сессия сбора.

---

## 0. Признание ошибки брифа

В брифе 05.10 написано «запрета на `/search` нет» — **это неверно**. Codex проверил и остановил
работу правильно: `https://www.prlib.ru/robots.txt`, строки 68–72:

```
# Search
Disallow: /search
Disallow: /en/search
Disallow: /prlib_sug
Disallow: /prlib_search
```

Я смотрел только первые 22 строки файла и сделал вывод по ним. Полнофондовый обход `/search`
**запрещён и запускаться не должен** — это зафиксировано, сомнений нет.
Проверка Codex: `output/prlib_v8_robots_gate_20261005/ROBOTS_GATE.json`.

## 1. Что из этого НЕ следует

Не следует, что ПрБ закрыта. В том же `robots.txt` **`/collections/` не запрещён ни в каком
виде** — ни сам раздел, ни поиск внутри коллекции. Прогон v7.1 ходил именно туда
(`/collections/467000/search?text=…`) и robots не нарушал; его беда была не в законности,
а в том, что коллекция 467000 — учебная подборка «Территория России», а не фонд.

не видно, но раздел пагинируется).

## 3. Задача v8

1. **Обойти семь региональных коллекций целиком** — не поиском по словам внутри них, а
   постраничным перечнем материалов коллекции (как мы делаем с описями архивов). Полнота
   внутри коллекции тогда гарантирована и не зависит от формулировок запроса.
2. Если перечень коллекции не отдаётся постранично — использовать поиск **внутри коллекции**
   (`/collections/<id>/search?text=…`), он разрешён; ключевые слова — те же шесть
   (`карта, план, атлас, съёмка, чертёж, топографическая`), территории — 49 из scope v7.1.
3. **Проверить типо-видовые коллекции** на наличие картографической.
4. Сохранить механику v7.1: состояние с возобновлением, журнал попыток, детектор конца
   пагинации, свёртку по url (одна карточка — одна строка, число попаданий в `hits`).
5. **robots:** `Crawl-delay: 2`; `/search`, `/en/search`, `/prlib_sug`, `/prlib_search`,
   `/?q=search/` — **не трогать ни при каких условиях**.

## 4. Гейт приёмки

- В `run_scope.json` явно записано, **какие коллекции обходятся** (id и названия), и эти URL
  видны в журнале запросов.
- Ни одного запроса к `/search` вне коллекции — проверяется по журналу.
- Выход свёрнут по url; для каждой записи — из какой коллекции получена.
- Числа: по коллекциям, по территориям, доля записей с годом и масштабом.

## 5. Что остаётся нерешённым

Региональные коллекции — это кураторские подборки, а не весь фонд ПрБ (876 122 библиотечных
материала). Поэтому даже успешный v8 даст формулировку «пройдены такие-то коллекции», но не
«ПрБ пройдена». Полнофондовый доступ возможен только по согласованию с библиотекой — это
задача для человека, не для скрипта. Предложение Codex получить разрешённый маршрут у
владельца сайта остаётся в силе как отдельная ветка.
