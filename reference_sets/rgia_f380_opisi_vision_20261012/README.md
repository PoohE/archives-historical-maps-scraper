## Ключ привязки к базе РГИА

**Карандашный сквозной номер в бумажной описи = номер единицы хранения = номер дела.**
Для оп. 37 независимо подтверждён итогами ревизии 1946 г.: в 7 уездах из 10 число
карандашных номеров точно совпало с «налицо» по штампу ревизора, диапазоны уездов
стыкуются без разрывов. Сквозная нумерация оп. 37 — 10–1119 без пропусков.

## Правила чтения этих описей

- **Две нумерации:** карандашная сквозная (= номер дела) и чернильная внутри рубрики
  (сбрасывается на 1 в каждой рубрике и каждом уезде).
- **Выбывшим карандашный номер не ставился** — нумерация через них перескакивает.
- **Сшивка:** один карандашный номер овалом на несколько чернильных строк = одно дело
  из нескольких планов (в оп. 37 таких 168). Отличать от фигурной скобки только в графе
  «подлинный план» — она объединяет датировку, а не дела.
- **«Перенесено» крест-накрест** = перенос в другую рубрику, не утрата.
- Смещение: **скан = лист + 4** (обе описи).

Подробнее — `op37/КОНТРОЛЬ_ПО_УЕЗДАМ.md` и скил `historical-handwriting`
(раздел «Архивные описи»).
