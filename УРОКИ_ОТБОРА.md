# Уроки отбора источников (самообучение на решениях человека)

Механизм-собрат `folder_lessons` (раскладка Articles), но по решениям приёмки.
**Область действия — только проект «Поиск онлайн архив».**

**Порядок работы.** ПЕРЕД отбором или написанием гейта — прочитать этот файл.
ПОСЛЕ очередной порции решений человека — `python scripts_review/catalog_review_lessons.py
--learn --note "…"`; выведенное из нескольких случаев — `--principle`.
Урок, противоречащий прежнему, не затирает его: прежний помечается `--supersede`,
и расхождение выносится пользователю.

## Принципы (выведены из нескольких случаев)

- **Делопроизводство учреждений отклоняется ВСЕГДА, даже по нашей территории: журналы уездных земских собраний и доклады управы, положения о земских учреждениях, правила о волостном обложении, издания библиотек, монастырские издания. Слово «план»/«карта» в таком заголовке предмета не создаёт (§1.1-бис).** (случаи: Журналы Чердынского Уездного Земского Собрания ×4, Издания областной библиотеки ×2, Об изменении положения о земских учреждениях, Об установлении правил о волостном обложении) — 2026-10-04, id `principle-01`
- **Территориальные описания и статистические исследования БЕРЁМ даже без слова «карта» в заголовке: «Верхнекамский край», «Результаты подворного исследования Верхне-Вычегодских волостей», «Торговый путь в Печорский край», «Исследование земских раскладок». Они дают привязываемые к территории данные — это каталог-БД, а не только карты (§1.1).** (случаи: Верхнекамский край, Результаты подворного исследования Верхне-Вычегодских волостей, Торговый путь в Печорский край, Исследование земских раскладок Вятской губернии) — 2026-10-04, id `principle-02`
- **«Чужая территория» по названию губернии НЕ является основанием для автоматического отсева: смежные территории исторического Прикамья (Верхнекамский край, Печорский край, Верхне-Вычегодские волости, Вятская губерния) принимаются. Из 14 записей класса «чужая территория + предмет не подтверждён» человек принял 4. Территориальный гейт по строке с названием губернии слишком узок.** (случаи: 4 из 14 записей класса other_region_in_title приняты) — 2026-10-04, id `principle-03`
- **Словесные ловушки подтверждены на практике: «Руководство-Атлас по столярно-мебельному мастерству», «Рассказ о великом плане», «план улучшенного полевого хозяйства для хуторов», «Карта новых железных дорог» — отклонены, несмотря на слова атлас/план/карта в заголовке. Предмет определяется объектом, а не словом (§1.1-бис).** (случаи: 4 из 5 записей класса «карта есть, территория не определена» отклонены) — 2026-10-04, id `principle-04`
- **Многотомные издания с картографическим содержанием («Топографическия известия… Российской империи») разбираются ПОТОМНО, а не целиком: из четырёх записей одна отклонена, три приняты. Решение принимается по конкретному тому, а не по названию серии.** (случаи: Топографическия известия Т.1 ×4: 3 приняты, 1 отклонена) — 2026-10-04, id `principle-05`
- **Данные, снятые человеком с изображения карты (масштаб, легенда), вносятся в запись с пометкой происхождения: у «Карты местности, населенной пермяками» масштаб 1:168000 и легенда (дороги, завод, рудник, мельница, село, деревня, починок) взяты с самой карты — в описании НЭБ их нет. Указанный в описании масштаб может относиться к ВРЕЗКЕ, а не к основной карте («Карта Смоленской губернии»).** (случаи: записи 7 и 9 листа проверки) — 2026-10-04, id `principle-06`
- **Один документ может лежать в НЭБ под разными catalog_id (пары 3↔4 и 5↔6 листа проверки): дедуп по заголовку недопустим (он склеит разные издания с одним названием), дубли выявляет человек и они помечаются взаимной ссылкой duplicate_of_url.** (случаи: пары 3-4 и 5-6) — 2026-10-04, id `principle-07`
- **«С N картами» в описании — ВСЕГДА причина взять запись, даже если сам документ книга/отчёт: lib.permkrai node/40880 принят именно по пометке «с 22 картами». Картографическое приложение внутри непрофильного издания делает запись нашей.** (случаи: Пермь node/40880, решение пользователя 2026-10-04) — 2026-10-04, id `principle-08`
- **«Атлас» ботанический/зоологический/анатомический (атлас растений и т.п.) — НЕ картографическое понятие и не берётся. Слово «атлас» в значении «иллюстрированный определитель» омонимично картографическому (§1.1-бис). Внесено также в онтологию проекта.** (случаи: Пермь node/37646, решение пользователя 2026-10-04) — 2026-10-04, id `principle-09`
- **Путеводители по области/краю отклоняются как слишком поверхностные: конкретных привязываемых сведений из них не извлечь. Подтверждает §1.2 (путеводитель по городу — drop) и расширяет его на областной уровень.** (случаи: Пермь node/37877 и node/40548, решения пользователя 2026-10-04) — 2026-10-04, id `principle-10`
- **Страница, ведущая на регистрацию/авторизацию, классифицируется как барьер доступа, а не как запись каталога: lib.permkrai node/2794. Такие узлы не идут ни в keep, ни в scope_drop по содержанию — у них отдельный статус «недоступно без регистрации».** (случаи: Пермь node/2794) — 2026-10-04, id `principle-11`
