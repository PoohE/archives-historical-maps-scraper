## Правила папки

- Здесь **обобщают, а не дублируют**: числа и факты берутся из итоговых наборов `output/`
  и из чеклиста, со ссылкой, а не переписываются по памяти.
- Каждый документ заканчивается блоком «Связи» — иначе материал теряется.
- Исторические артефакты (`output/*`) не правятся; при переоценке — новый документ с датой.
- Файл, адресованный человеку (справка для поездки, сводка), пишется так, чтобы его можно было
  отдать коллеге без пояснений от нас.
