# Регламент закрытия архива — что обновлять ВСЕГДА, без напоминания

Версия 1.0, 2026-10-02. Выполняет сессия сбора **автоматически** по завершении работы
с источником (архив/библиотека), до перехода к следующему. Пользователю говорить не нужно.

---

## Триггер
Прогон по источнику завершён: охват закрыт (или честно зафиксирован `partial`), гейт отбора
применён, набор кандидатов готов.

## Чек-лист — 6 пунктов, все обязательные

### 1. `docs/current/!!чеклист архивов.md` — оперативная сводка
Обновить строку источника в таблице: **«Подтверждённое состояние»** (что реально собрано, числа)
и **«Ближайшая граница»** (что дальше / чего НЕ доказано). Устаревшую формулировку заменить,
не дописывать рядом.

### 2. `PROGRESS.md` — чекпойнт + статус
- Добавить чекпойнт сверху: что собрано, чем, числа, грабли.
- Обновить таблицу **СТАТУС АРХИВОВ** (собрано / состояние).
- Обновить блок «подготовка продолжения» — убрать выполненное.

### 3. `ПРАВИЛА_ОТБОРА_источников.md`
Если при работе вводилась **региональная поправка** или уточнялось правило — внести в таблицу
поправок и в журнал решений (с датой и автором решения). Точечные исключения не заводить.

### 4. Notion — справочник «Архивы», ТОЛЬКО операционные поля
Справочник `collection://fedbea82-520d-4f03-b8bc-793a29a25e79` — **совместный**, разделение
по полям (решение пользователя 2026-10-02):

| За СБОРОМ (эта сессия) | За КАТАЛОГОМ (`claude-4e`) |
|---|---|
| `Автосбор: состояние` | записи источников в каталоге |
| `Автосбор: полнота` | название, аббревиатура, город, адрес, телефон, email, сайт |
| `Метод поиска` | тип, приоритет, ключевые фонды, особенности |
| `Проблема доступа` | состояние описания, статус доступа, веб-поиск |
| `Обходной путь` | |

**Почему так:** операционные поля — факты, добытые прогоном («Пермь только headed Chrome, QUIC»;
«robots запрещает /search/»; «fgurgia soft-банит под длительной нагрузкой»; «ф.192 — сканы,
нужен OCR»). Их никто, кроме сессии сбора, корректно не заполнит.

⛔ **Записи источников в Notion-каталог НЕ писать** — только передавать набор (пункт 5).
Это зона каталога; двойной импорт уже давал дубли.

### 5. Передача соседней сессии (каталогизация → Notion-каталог)
**Отправить `SendMessage` сессии `claude-4e`** (сессия каталогизации) с:
- путём к набору кандидатов (CSV/JSONL),
- числами: собрано / отсечено по гейту / с разбивкой причин,
- списком спорных записей, требующих человеческого суждения,
- ссылкой на применённые правила (`ПРАВИЛА_ОТБОРА_источников.md`).
Пользователю об этом сообщать не нужно — он просил автоматизм.

### 6. GitHub — коммит в рабочую ветку проекта
Репозиторий: **`PoohE/archives-historical-maps-scraper`** (origin), рабочая ветка — **`master`**.
Коммитить по завершении источника:
- документы и правила (`ПРАВИЛА_ОТБОРА_источников.md`, `РЕГЛАМЕНТ_закрытия_архива.md`,
  `PROGRESS.md`, `docs/current/!!чеклист архивов.md`, брифы `CODEX_BRIEF_*.md`),
- recon-артефакты и списки кандидатов (`output/*_recon_*`, `*_candidates.json`, вердикты гейта).

⚠️ **Репозиторий общий с Codex** — в рабочем дереве постоянно висят его незавершённые правки
(на 2026-10-02 — 222 изменённых файла). **НИКОГДА не делать `git add -A` / `git commit -a`** —
это сгребёт чужую незакоммиченную работу в свой коммит. Добавлять **только свои файлы поимённо**
(`git add <конкретные пути>`), сообщение — по смыслу закрытого источника. Перед индексной
операцией убедиться, что в репозитории не работает параллельная сессия; при
`index.lock: Permission denied` — остановиться и не удалять lock вручную.

### 7. Память проекта
Если всплыл урок, который нельзя повторять (транспорт, маршрут, грабля гейта) — дописать в
`memory/project_archive-crawl-quirks.md` и строку индекса в `MEMORY.md`.

## Принцип честности
Не писать «закрыт», если закрыт только один маршрут. Формулировать точно:
«рубрика закрыта, поиск не покрыт», «опись-уровень собран, дела — сканы, нужен OCR».
Полнота заявляется только по тому охвату, который реально доказан.
