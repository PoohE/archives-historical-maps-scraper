# review-run — разбор прогона перед Notion

Инструмент этапа `run_search → **review-run** → notion_export → Notion`. Оркестрирует
детерминированный скрипт `scripts/run_review.py` (механика) и интерактивный `scripts/review.py`
(ручная отбраковка), сверяет дубли с базой Notion и готовит чистый набор к импорту.

Критерии отбора — «Критерии выборки источников — ветка РНФ»
(`2026 РНФ/Обсуждение/2026 06 критерии источников/`): территория (4 губернии + 46 уездов) ×
картографические триггеры × период (нижняя 1600, верхняя ≈1939). Название часто не отражает
содержание → инструмент только грубо отсеивает шум и готовит корзину для быстрой ручной проверки;
итоговая верификация — в самом архиве.

## Когда применять
Есть свежая папка прогона `output/<run>/` с `records_full.jsonl`, и её результаты нужно
отфильтровать, дедуплицировать и подготовить к заливке в Notion «Каталог исторических источников
для ИГИС по проекту РНФ».

## Шаги

### 1. Определить папку прогона
Уточнить у пользователя `output/<run>` (или взять последнюю с `records_full.jsonl`).

### 2. Выгрузить уже занесённые в Notion URL (сеть — здесь, в скиле)
Через Notion MCP запросить существующие ссылки базы «Каталог» (data source
`collection://decdf63c-6f64-4852-ada2-65e72c79d9bc`):

```sql
SELECT "Ссылка на онлайн-архив" AS url
FROM "collection://decdf63c-6f64-4852-ada2-65e72c79d9bc"
WHERE "Ссылка на онлайн-архив" IS NOT NULL
```

Сохранить результат в `output/<run>/notion_existing.json` в формате:
```json
{ "urls": ["https://...", "..."], "keys": [] }
```
(Первичный ключ диффа — URL «Ссылка на онлайн-архив». Вторичный ключ по шифру/названию
работает внутри прогона; против Notion — по URL.)

### 3. Прогнать ядро (детерминированно, оффлайн)
```bash
python scripts/run_review.py output/<run> --existing output/<run>/notion_existing.json
```
Выход в `output/<run>/review_run/`: `review.csv` (на ручную), `accepted_records.jsonl`
(авто-оставить), `review_records.jsonl`, `dropped.csv`, `report.json`.
Показать пользователю `report.json` (сколько уникальных, авто-оставить / на ручную / отсеяно,
причины отсева).

### 4. Быстрая ручная отбраковка корзины «на проверку»
```bash
python scripts/review.py output/<run>/review_run
```
`Enter` — оставить (карта), `n` — убрать, `s` — отложить, `q` — выход (прогресс сохраняется).
Показывается колонка «Причина» (сомнительный тип / регион неясен / год не указан). Подтверждённые
дописываются в `accepted_records.jsonl`.

### 5. Экспорт принятого набора в Notion-CSV
```bash
python scripts/modules/notion_export.py output/<run>/review_run/accepted_records.jsonl --output output/<run>/notion_import
```
Даёт `notion_import.csv` + `export_review.json` (все записи — `candidate`, ручной гейт на заливку).

### 6. Отчёт
Свести: входных записей → уникальных → авто-оставить / принято вручную / отсеяно / уже в Notion;
путь к `notion_import.csv`. Заливка в Notion — отдельный шаг (ручной гейт), не автоматически.

## Определение готовности
`notion_import.csv` получен, дубли (внутри прогона и против «Каталога» по URL) убраны, отсев
зафиксирован в `dropped.csv`/`report.json`.

## Границы
- Скрипты — оффлайн; сеть (Notion) только на шаге 2 внутри скила.
- Инструмент не заливает в Notion сам — только готовит CSV.
- Файлы прогона — на Яндекс.Диске: при работе просить паузу синка на других машинах.
