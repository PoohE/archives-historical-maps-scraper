# archive-visit-cataloging — внесение данных архивной поездки в каталог ИГИС

Выработан 29–30.10.2026 на 10 эталонных делах (РГИА ф.380 и ф.1424). Полная методика и все
решения с обоснованием — в `docs/current/ПРАВИЛА_полевой_каталогизации_в_архиве.md`
(читать перед первым применением скила в новой сессии). Эта страница — краткий рабочий
протокол, не дублирует детали правил.

## Процесс (для КАЖДОГО дела)

1. Найти запись в Notion по Фонду/Описи/Делу (`output/notion_catalog_*.csv` локально — быстрее,
   чем прямой query к большой базе; либо `client.pages.retrieve` по известному page_id).
2. Прочитать текущее состояние карточки (не затирать вслепую).
3. Собрать черновик полей (см. семантику ниже) и показать пользователю **целиком одним
   сообщением**, не по одному полю — если пользователь сам не попросит иначе («давай по
   одному полю»). Применять только после подтверждения/правки.
4. Если решение участника поездки было «не брать» / «дубль» / «для специальных
   исследований» — **не считать это автоматически решением по каталогу**. Переспросить:
   обычно «не брать» = приоритет сканирования/геопривязки, НЕ исключение из каталога
   (кроме явного «дубль» — тогда отклонять с примечанием на основную запись).

## Семантика полей (не путать!)

| Поле | Что туда идёт |
|---|---|
| **Описание** | Карта ПЕРВЫМ пунктом (наш приоритет), текст-приложения после |
| **Содержимое** (rich_text, нумерованный список) | Порядок КАК В ДЕЛЕ (главный документ по мнению составителей XIX в. первым — не обязательно карта) |
| **Листы / страницы** | Архивный учёт, НЕ трогать при полевом внесении |
| **Размер листа (мм)** | Полный физический размер карты, формат `W×H мм (W×H см)` — уже используется по всему каталогу |
| **Размер карты** | НЕ число — методика расчёта (сетка фрагментов, реставрационная резка и т.п.), когда размер не обмерен, а посчитан |
| **Год создания (нижняя/верхняя)** | Архивный год ДЕЛА, не трогать |
| **Год источника** | Год САМОЙ КАРТЫ, если отличается от года дела |
| **Автор / составитель** | Автор КАРТЫ (землемер/межевщик), не автор текстовых приложений |
| **Оригинальный масштаб** | Точная архивная формулировка («4 версты в англ. дюйме», не упрощать) |
| **Техника исполнения** | Обычно «Рукописная» для этого типа поездок (уточнить на партию дел сразу, не разово) |
| **Место создания** | Учреждение + губерния (напр. «Пермская палата государственных имуществ»), не город хранения |
| **Серия / массив** | Привязывать ТОЛЬКО когда происхождение/основа карты подтверждены; если под вопросом — оставить пустым, зафиксировать вопрос в Примечаниях |
| **Типы отображаемых объектов** (relation) | Только широкие категории, которые реально подходят (их 8: Административные границы, Угодья и землепользование, Пути сообщения, Рельеф, Леса, Промышленные объекты, Населённые пункты, Гидрография). Если объект не подходит ни под одну — НЕ придумывать новую категорию без крайней необходимости, детали оставить в Описании текстом |

## Масштабные классы внутри серии «Генеральное межевание»

Одна серия содержит НЕСКОЛЬКО формальных классов дел с разным устойчивым пакетом документов
-- не один общий набор. Полная структура (поля каждого типа документа, с сохранением
иерархии исходных таблиц) -- в теле страницы серии в Notion (база «Серии / массив», запись
«Генеральное межевание») и дублируется в
`Dropbox/Project/Articles/2_Историческая картография/20_Источники/22_Межевание (ГМ, Менде,
инструкции, землеустройство)/Стандартные_формы_табличных_приложений_Генерального_межевания_РГИА_ф380.md`.

- **Класс А (уездная карта)** — 1 карта + 4 типа текста уездного свода. Эталон: д.418.
- **Класс Б (волостная карта)** — 3 картографических компонента + 2 типа текста. Эталон: д.712.
- **Класс В (уровень дач)** — карта конкретной дачи/группы деревень + до 6 типов текста.
  Эталон: д.676.

При новом деле серии — определить класс по структуре (не по формальному названию), при
нехватке класса под структуру -- завести новый прямо в документации серии, не смешивать с
существующими.

## Открытые методологические вопросы (не решать самостоятельно, фиксировать и откладывать)

- Роль уровня дач в Генеральном vs Специальном межевании -- отложено до исследования истории
  серийных карт.
- Основа тематических губернских карт (межевание vs атласы Менде) -- проверять по делу, не
  предполагать по умолчанию.
