# Правила отбора источников — единый гейт для ВСЕХ прогонов

Версия 1.0, 2026-10-02. **Единственный источник истины** по критериям отбора.
Опора: `docs/current/МЕТОДОЛОГИЯ_СТАТЬИ.md` §2.2 + решения пользователя 2026-10-02.
Изменения — только совместно с пользователем, с записью в журнал внизу.

---

## 0. Зачем этот документ

Критерии отбора раньше жили **в формулировке поискового запроса** (искали «карта Калужская
губерния» — территория фильтровалась сама). У **рубричных** источников (Пермь `/node/722`)
запроса нет, рубрика берётся целиком — и критерии не применялись НИ В ОДНОЙ точке.
Результат: в выборку Перми попало 7 городских карт вне охвата.

**Правило:** критерии отбора — это **отдельный гейт ПОСЛЕ извлечения**, одинаковый для всех
источников, независимо от способа обнаружения записи (поиск / рубрика / обход описей / OCR).

---

## 1. Общий гейт (применяется ко ВСЕМ источникам)

### 1.1 Предметный критерий

⚠️ **РАСШИРЕНО 2026-10-02.** Каталог — не собрание карт, а **база данных**: картографические
источники **И данные, привязанные к объектам на карте**. В охват входят статистика и
экономические примечания — но **только привязанные** к картографическому объекту:
**даче, уезду, губернии, конкретному объекту межевания**.

| Берём | Не берём |
|---|---|
| карта, план, атлас, схема, чертёж, картограмма, топографическое описание с картами | |
| **экономические примечания к планам дач** (ф.1355), перечневые табели, каталоги к генеральным планам, алфавиты дач и владельцев | |
| **статистика и описания с привязкой** к даче / уезду / губернии / объекту межевания | статистика **без** территориальной привязки к объекту |
| полевая съёмочная документация (полевые записки, планы землеустроительных работ) | **чистое делопроизводство**: журналы и протоколы контор, переписка, указы — без привязки к объектам |

Технически у источников с типизацией — маркер оцифрованной карты (напр. Пермь: `node-type-pdf`;
НЭБ: поле «Каталог» содержит «карт»). Для расширенного охвата маркер карты **не обязателен** —
решает наличие привязки к картографическому объекту.

*Прецедент возврата:* в РГИА под старым правилом отсеялись как `not_cartographic` 12 записей
(«Департамент государственных земельных имуществ… План…», «Отдел сельского строительства…
План работ по разверстанию…») — землеустроительная документация с привязкой к губернии.
Под расширенным §1.1 они **включаются**.

**НЕ картография:** «план работы», «план счетов», «учебный план», «пятилетний план»,
«план мероприятий» — документы, не карты. Отсекать.

⚠️ **ИСКЛЮЧЕНИЕ (уточнено 2026-10-02 по живому отсеву):** словосочетание «план … работ»
является КАРТОГРАФИЕЙ, если есть землемерный/картографический контекст:
*землеустроительн*, *межев*, *съёмк*, *полевой период*, *нивелир*, *топограф*, а также привязка
к губернии/уезду/даче. Шаблон «план работы» писался против административных документов и не
должен ловить полевую документацию.
*Прецедент:* «**План землеустроительных работ на полевой период 1915 г. по Пермской губернии**»
был ошибочно отсечён гейтом как `not_cartographic` — это профильная карта (землеустройство,
уровень губернии, 1915), подлежит включению.
**Различение:** «план работы/мероприятий/счетов» = документ учреждения; «план землеустроительных
(межевых, съёмочных) работ» = результат полевой съёмки, картография.

### 1.1-бис Слова-ловушки: предмет подтверждается ТОЛЬКО вместе с территориальным якорем

⚠️ **Введено 2026-10-02 по живому отсеву Перми tier A.** Ключевое слово в заголовке само по себе
предмета НЕ доказывает. Проход только если картографический признак **и** территориальный якорь
(губерния / уезд / волость / регион / дача / объект межевания) подтверждены **полями самой записи**.

| Слово | Ложное срабатывание | Правило |
|---|---|---|
| *топограф** | «Пути оттока крови при перевязке нижней полой вены» (топография органов), «К номенклатуре, **топографии** и хронологии свадебных чинов» | только с территориальным якорем |
| *карт**, *план* | «Справочник работника АТК», «Становится историей война», «Мифы древних славян» — слово встречается в тексте карточки, а не в предмете | предмет берётся из заголовка/типа, не из полнотекста |
| фамилии и имена | «Дело о дворянстве **Карташевых**» (РГИА) | морфология слова «карта», не `карт\w*` |

Это та же ошибка основания, что у `needs_human` в РГИА: признак брался из поискового запроса или
полнотекста карточки, а не из полей записи.

### 1.2 Территориальный уровень — ЕДИНИЦА АНАЛИЗА
По §2.2 единица анализа — **49 административных территорий**: 4 губернии, 4 наместничества,
41 уезд. Дополнено решением пользователя:

| Уровень | Берём? |
|---------|--------|
| Губерния / наместничество | ✅ да |
| Уезд | ✅ да |
| Волость | ✅ да |
| **Регион ≈ губерния** (край, область, историко-географический регион советского периода — напр. **Урал**, **Пермский край**) | ✅ да |
| **ГОРОД** (план г. N, карта города, городские транспортные и туристические схемы, **путеводитель по городу** — в т.ч. по уездному) | ❌ **НЕТ** |
| **Карта уезда с приложенным планом города** («Карта Ростовского уезда Ярославской губернии и план города Ростова») | ✅ **да** — единица уездная, городской план лишь приложение |
| **Отдельный объект вне админ-уровня** (природный/хозяйственный объект сам по себе) | ❌ нет |

*Пример отсечения по уровню:* «Кунгурская ледяная пещера» — природный объект, не губерния/уезд/
регион → **drop по §1.2**, не точечное исключение.

**Различение город vs регион — по территориальному субъекту в заголовке:**
«туристическая карта Пермского **края**» → keep; «туристическая карта **Перми**» (город) → drop.

### 1.3 Территориальная релевантность
Запись должна относиться к **исследуемым территориям** (4 губернии и соответствующие им
регионы). Карты других стран/регионов, лежащие в фонде просто потому, что их держит данная
библиотека, — **исключать**.

*Примеры отсечения по релевантности (все — по §1.3, не точечные исключения):*
- «Atlas universel» — мировой атлас;
- «Карта русско-германско-австрийского театра военных действий» (1914) — чужой театр;
- «Карта неба», «Этноатлас Дагестана», «Атлас по геометрической кристаллографии».

Границу проводит человек на приёмке (автомат не всегда отличит), но **основание — это правило**,
а не разовое решение.

### 1.4 Хронология — различать АРХИВЫ и БИБЛИОТЕКИ (уточнено 2026-10-02)

**Нижняя граница — отсутствует. Жёстко: НИКОГДА не отсекать снизу.**
Чем старше материал, тем он ценнее и реже. Отсечка снизу уничтожает именно то, ради чего ведётся
сбор (чертежи XVII в. и ранее). Параметр `year_from` из scope источников **убрать**.
*Прецедент: в РГИА стоял `year_from: 1700` — резал допетровские чертежи.*

⚠️ **УТОЧНЕНИЕ 2026-10-03: материалы ранее ~1700 г. в охват НЕ входят — но по §1.2, не по дате.**
Причина не хронологическая, а территориальная: губернское деление введено с 1708 г., и
допетровские чертежи **не привязываются к нашим 49 административным территориям**. Непривязанное
дело невозможно ни сопоставить, ни заказать — оно не отвечает задаче исследования.
Формально это `non_admin_object` / отсутствие территориального якоря (§1.1-бис), а НЕ `year_from`.
**`year_from` в scope по-прежнему НЕ задаётся** — отсечка делается гейтом по территории,
и запись остаётся в `scope_drops.jsonl` с причиной, а не исчезает из сбора.
*Следствие:* хронологический добор по 13 запросам РГИА, шедшим в v13.6 с `year_from: 1700`,
**не проводится** (решение пользователя 2026-10-03).

**Верхняя граница — объявленный параметр источника, а не суждение в моменте.**

| Тип источника | Политика |
|---|---|
| **Библиотеки** | Верхняя граница НЕ задаётся — собираем всё до конца XX в. Поздних картографических материалов мало, они ценны (туристические карты 1950-х — показывать). |
| **Архивы** | Допускается `collect_until` — там, где поздний слой (вторая половина XX в.) настолько массов, что топит сбор и не отвечает задаче. |

**Механика (обязательна, иначе правило не применять):**
1. В `scope.json` источника — поле **`collect_until`** (год) и **`collect_until_reason`**
   (обоснование словами, с числом). Нет обоснования → нет отсечки.
2. Обоснование даёт **разовый замер**, а не ощущение: перед сбором посчитать, сколько попаданий
   по нашим запросам приходится на период после порога. Результат записывается в
   `collect_until_reason` («слой после 1945 — N тыс. ед., нерелевантен задаче»).
3. **Где объём не угрожает прогону — помечать, а не выбрасывать.** Отсечение необратимо без
   повторного прогона; пометка периода стоит почти ничего, решение переносится на приёмку.

⛔ **Запрещено правило «если материалов много — отсекаем, если мало — включаем», применяемое
по ходу сбора.** Объём неизвестен до окончания сбора (замкнутый круг), корпус перестаёт быть
воспроизводимым, а основание решения не восстанавливается позже. Только объявленный порог
с записанным обоснованием.

### 1.5 Тематические карты — берём
Тематика (посевы, гидрография, полезные ископаемые, промышленность и т.п.) **в охвате**,
если территориальный уровень подходит (губерния / уезд / регион).

согласованию с пользователем** и записывается сюда.

> Точечных исключений в этой таблице нет и быть не должно: каждая отсечённая запись должна
> отсекаться **общим правилом** (§1.1–1.4). Если запись «хочется убрать», но под правило она не
> попадает — значит правило неполное, его и надо уточнить, а не заводить исключение.

## 3. Где применяется

Гейт — **общий модуль**, вызываемый каждым сборщиком после извлечения записи, ДО записи в
candidate-набор. Не дублировать логику в каждом раннере.

| Источник | Способ обнаружения | Гейт нужен? |
|----------|--------------------|-------------|
| РГИА, РГАДА, ПрБ | поиск по территории+слову | да (территория в запросе, но уровень/город — нет) |
| **Пермь** (рубрика /node/722) | рубрика целиком | **да — критично** (дыра была здесь) |
| НЭБ (рубрики/поиск) | search + карточки | да |
| Будущие рубричные/коллекционные | обход целиком | да |

Каждая отсечённая запись сохраняется с причиной (`scope_drop_reason`: `city_level`,
`not_cartographic`, `out_of_region`, `manual`), НЕ удаляется молча — чтобы решение можно было
пересмотреть.
