## 1. Что пошло не так

Прогон v7.1 отработал **штатно** (`query_scope_completed`, exit 0, 294/294 запроса, трое суток)
и дал **36 уникальных карточек**, из них картографических 4. Причина не в сбое, а в области
поиска: все запросы уходили по адресу

```
https://www.prlib.ru/collections/467000/search?text=<слово>+<территория>&page=N
```

— то есть **внутрь коллекции № 467000**. Это, по данным самого сайта,
«Президентская библиотека — учителям: обучение с использованием первоисточников» →
История → Общие коллекции → **«Территория России»**: учебно-просветительская подборка,
а не фонд библиотеки.

**Следствия, видные в данных:**
- **341 запрос из 379 дал ноль записей** (`records_yielded: 0`) — в учебной подборке нет
  материалов по Мосальску, Медыни, Чердыни и прочим уездным центрам;
- найденное — преимущественно хрестоматийные тексты («Списки населённых мест»,
  «Материалы для географии и статистики»), а не карты;
- узкий запрос по короткому топониму «Оса» (уездный центр Пермской губернии) выцепил из
  разнородной подборки «Осаду полюса» (1934) и описания осад Пскова и Казани.

**Масштаб потери.** Полнофондовый поиск `https://www.prlib.ru/search?text=…` на том же запросе
показывает: **Библиотечные материалы — 876 122**, **Архивные материалы — 394 705**,
Материалы сайта — 31 341. Мы обходили подборку на несколько сотен единиц вместо фонда почти
на миллион.

## 2. Задача: пакет v8 — полнофондовый маршрут

1. **Разведать полнофондовый поиск** `https://www.prlib.ru/search`:
   - структура запроса и пагинации (параметры, лимит на страницу, предел глубины);
   - три раздела выдачи — «Библиотечные материалы», «Архивные материалы», «Материалы сайта»:
     какой параметр их переключает, нужны ли нам архивные (вероятно да: там дела фондов);
   - **«Расширенный поиск»** — есть ли фильтр по **виду материала (картографические)**,
     по датам, по месту издания. Это ключевой вопрос: фильтр «карты» сокращает миллион до
     обозримого и снимает проблему ловушек короткого топонима.
2. **Собрать маршрут** по образцу v7.1: территории (49 из `run_scope.json` v7.1) × ключевые
   слова (`карта, план, атлас, съёмка, чертёж, топографическая`), но по фонду, а не коллекции.
   Если найдётся фильтр по виду материала — territory-запрос + фильтр «картографические»
   предпочтительнее, чем слово в тексте.
3. **Сохранить достижения v7.1**: состояние с возобновлением, журнал попыток, детектор конца
   пагинации, `classifier_verdicts`, устойчивость к обрыву.
4. **Учесть robots:** `prlib.ru/robots.txt` — `User-agent: *`, **`Crawl-delay: 2`**; AhrefsBot
   запрещён целиком. Запрета на `/search` нет, но темп держать по crawl-delay.

## 3. Чего ждать на приёмке (гейт)

- В `run_scope.json` явно записано, **по какой области идёт поиск** (фонд, а не коллекция),
  и этот URL виден в журнале запросов — чтобы повтор моей ошибки был заметен сразу.
- Доля запросов с нулевым результатом **существенно ниже** нынешних 90 % (341 из 379).
- Выход свёрнут по url (одна карточка — одна строка), поле `hits` сохранено.
- Для каждой записи — вид материала, если портал его отдаёт.
- Числа в отчёте: запросов, карточек, по территориям, по виду материала.

## 4. Границы

- Старый выход v7.1 **не удалять и не переписывать**: исторический артефакт, на него уже
  ссылается чеклист и переданный в каталог набор. Новый прогон — новый каталог `*_v8_*`.
- Передача в Notion — не зона сборщика; набор отдаётся сессии каталогизации.
- Разведку вести вежливо: crawl-delay 2 с, без параллельных потоков.
